3. scripts：`typecheck = tsc --noEmit`；`test:unit = vitest run tests/unit`；`test:contracts = vitest run tests/contracts`。现有dev/build scripts保持。
4. 测试通过Node vm或等价隔离环境读入真实mic-capture.js，注入假的AudioWorkletProcessor及registerProcessor，并捕获实际postMessage的payload及第二参数transfer list，不重写被测采集算法。
5. 覆盖下列明确断言（浮点比较容差1e-6）：
   - 无输入返回true，不发消息。
   - 连续五块128个常量0.5样本：前四块不发，第五块仅发一帧640样本，RMS=0.5。
   - 输入长度不整除640时保留余数，跨process拼接正确。
   - 两帧0.25/0.75得到各自RMS；第二帧写入不改变第一帧payload。
   - transfer list第一个buffer属于这次输出；不能发送仍会复用的内部buffer。
   - 静音640样本RMS=0，无NaN。
6. 先确认测试有意义：临时测试内错误预期应使测试失败，恢复正确预期后通过；不修改生产src制造红测。记录验证过程。
