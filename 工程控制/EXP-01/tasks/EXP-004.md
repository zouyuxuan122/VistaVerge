# EXP-004 三维场景：精致电脑 + 占位人物 + VRM 接口

## 目标
实现 UI_UX_AVATAR.md §1.3/§3 的渲染层：真实感电脑建模 + 分层驱动的人物适配器。

## 文件域
desktop/src/scene/**、desktop/tests/unit/scene-*.test.ts。禁止：ui/app/services/data。

## 接口
```ts
// scene/AvatarScene.ts
class AvatarScene { constructor(canvas); setState("idle"|"listening"|"speaking"|"working"); setMouthOpen(v0to1); setGaze(x,y); setAudioClock(fn|null); setQuality("high"|"low"); dispose() }
// scene/computer.ts — buildComputerScene(): Group（显示器含发光屏、独立键帽InstancedMesh、鼠标、线材CatmullRom、桌面、支架）
// scene/avatar.ts — class PlaceholderAvatar implements AvatarRenderer（明确 isPlaceholder=true；眨眼循环、视线、张嘴、坐姿、打字臂动）
// scene/vrmAvatar.ts — loadVrm(url, licenseMeta) via three-vrm；缺资产/未声明许可 → 拒绝并保留占位（isPlaceholder 不变）
```

## 步骤
1. 灯光：key/fill/rim + RoomEnvironment；ACES tone mapping；阴影 PCFSoft。
2. 电脑：显示器 16:9 边框+发光屏（屏面用 CanvasTexture，可写任务状态）、键盘底座+键帽阵列（InstancedMesh，≥60键）、鼠标、线缆、桌面木纹色+圆角、接触阴影。
3. 人物：程序化几何（头/眼/睑/颌/躯干/手臂关节组），坐姿面向电脑；眨眼随机间隔、视线 lerp、speaking 时 mouthOpen 跟随 setMouthOpen；working 时手臂往复敲击。
4. 音频时钟：setAudioClock 接 AnalyserNode RMS→mouthOpen（标注近似，非viseme）。
5. 质量档：low 关阴影/降像素比。
6. TDD 逻辑层（无GPU）：状态机、mouthOpen clamp、眨眼计时（假时钟）、键帽计数、dispose幂等、VRM许可门。
