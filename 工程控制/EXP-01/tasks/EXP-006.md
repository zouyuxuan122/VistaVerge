# EXP-006 插件、感知、教师与任务服务

## 目标
实现 PLUGIN_PLATFORM_UPDATES 骨架、DOMAIN_PLUGINS 的天气/提醒/HA 适配、TEACHER 基础闭环、工具注册表。

## 文件域
desktop/src/plugins/**、desktop/src/sensors/**、desktop/src/teacher/**、desktop/src/ui/{MarketView,TeacherView,MemoryView,ReminderToast}.vue、desktop/tests/unit/{plugins,sensors,teacher}-*.test.ts。禁止：改 services/data/scene 内部（可经其公开接口使用）。

## 接口
```ts
// plugins/tools.ts
registerTool({name,describe,schema,execute,permissions}) / runTool(name,args,ctx)  // ctx含权限裁决；未知工具拒绝
内置: memory.search、weather.get、time.now、reminder.create
// plugins/manifest.ts — parseManifest(json): 校验 id/version/sdkRange/kind/permissions/license；非法拒绝
// plugins/registry.ts — fetchIndex(url)→校验→install(data包: theme|character JSON)→本地目录；sha256核对、大小上限、路径白名单
// sensors/weather.ts — Open-Meteo(无key) fetch，{observedAt,expiresAt}，离线报错
// sensors/haClient.ts — HA WebSocket auth/get_states/subscribe；无配置→status blocked
// sensors/reminders.ts — 出门触发(“我要出去/出门了/再见”)→天气+tag:出行记忆→合并一条；安静时段；会话内去重
// teacher/study.ts — 导入txt/md→行锚点chunk；quiz(经LlmProvider)；grade(客观题确定性+证据)；错题表+SM-2轻量复习
// plugins/taskService.ts — tasks 表 CRUD + 状态机 NOT_STARTED/IN_PROGRESS/DONE/BLOCKED + 单执行租约
```

## 步骤
1. TDD 每模块；LLM 均经 EXP-003 的 provider（mock 可测）。
2. 工具权限：manifest 声明 vs 运行时授予，未授予拒绝；工具返回不可信标记。
