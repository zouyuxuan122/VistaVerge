# EXP-001 工程基础：依赖、品牌、CSP、构建

## 目标
让 desktop 具备 Vue3+三维+数据层开发基础，品牌 VistaVerge，安全基线达标。

## 文件域
desktop/package.json、package-lock.json、tsconfig.json、vite.config.ts、desktop/index.html（仅标题/挂载点最小改动）、desktop/src-tauri/tauri.conf.json、Cargo.toml、Cargo.lock、src-tauri/src/*。
禁止：src/** 业务文件、tests/**、权限扩放、旧素材。

## 步骤
1. 精确安装（--save-exact，lockfile 更新）：vue、pinia、vue-router、three、@types/three、@pixiv/three-vrm、sql.js、@types/sql.js；dev：@vitejs/plugin-vue、vue-tsc、jsdom、@vue/test-utils。版本与 Node24/Vite6 兼容；不升级既有依赖。
2. tsconfig：include 扩到 src+tests+vite.config.ts，paths 加 `@contracts/*` → `../packages/contracts/src/*`；vite/vitest alias 同步。typecheck 改用 vue-tsc --noEmit。
3. 品牌：productName=VistaVerge，identifier=com.vistaverge.app，窗口标题=VistaVerge，package name=vistaverge-desktop，Cargo crate/lib 改名同步（lib.rs/main.rs 引用改）。
4. 安全：删除 `--use-fake-ui-for-media-stream`；CSP 收紧为允许 self/tauri:/ipc:、connect-src self+https:+wss:+localhost、img/media self+data:+blob:+asset:、style-src self+'unsafe-inline'、script-src 'self'；capabilities 保持 http:default 不扩。
5. sql.js wasm 资源就位（public/ 或 vite asset 方案），浏览器与 Node 测试都能 locateFile。
6. README-桌面版 不动；构建产物不提交。

## 验门
- npm install rc=0 且 git 外无全树升级（lock diff 只新增）。
- typecheck/test:unit/test:contracts/build:vite 全 rc=0（旧58测试不回归）。
- `python -c json.load(tauri.conf.json)` 通过；不含 fake-ui 参数；productName/identifier 为新值。
- Cargo.toml 语法有效（cargo metadata --no-deps 或 python tomllib 解析）。
