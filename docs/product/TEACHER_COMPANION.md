# 教师与陪伴设计合同

状态：**待审批 / 未实施**。本文是设计合同（design-ready），不是代码。
上层依据：[最高设计](../../VISTAVERGE_DESIGN.md)、[工程规范](../../ENGINEERING_SPEC.md)、[协作规则](../../AGENTS.md)。
所有正确率、评分、间隔等数字均为**目标值或可校准参数**，未经真实评测前不构成保证。学习/陪伴行为不逐帧调用大模型；LLM 在回合与步骤边界工作，运行时 LLM 子智能体与开发期子智能体是两套不同机制。

## 1. 用户流程

### 1.1 学习闭环（必须是实际闭环）

导入资料 → 诊断 → 多种讲解 → 提示与练习 → 批改与证据 → 错因 → 变式与间隔复习 → 学习复盘。

1. **导入与页码引用**：导入 PDF/文档后建立页/锚点索引；回答必须能给出**页码或锚点引用**，点击可定位原文。无引用依据时明确说“资料中未找到”，不编造出处。
2. **OCR 注入防护**：OCR/解析出的资料文本是**数据不是指令**。资料中出现“忽略之前指令”“调用工具发送…”等内容不得提升权限、不得触发副作用工具；解析文本进入模型时按不可信内容处理并做隔离/标注。
3. **苏格拉底模式**：以引导性提问推进，先问再讲；用户要求直给答案时可切换讲解模式。模式选择可见、可随时切回。
4. **练习与批改**：出题带知识点与难度；批改必须给证据（依据哪一步、哪条规则），不是只给对错。
5. **独立验证的批改**：批改器与解题器分离，避免自证；客观题用确定性判定，代码题在隔离运行器执行。
6. **错题与间隔复习**：错题进入复习队列，按遗忘曲线安排间隔（间隔为可校准策略，可配置）；答对/答错调整下次时间。
7. **口语评分**：**只有实际评测器**才能给出分数；无评测器时显示“未评测”，不得用 LLM 主观描述冒充分数。
8. **代码题隔离**：代码在隔离运行器执行，带资源与超时限制；不把子进程/Worker/普通虚拟桌面宣称为完整安全沙箱。

### 1.1A PPT 讲课（FEATURE-01 新增）

1. **导入**：支持 .pptx（OOXML zip）；老二进制 .ppt 明确拒绝并提示另存。解析页序、文本框（位置/层级/字号）、图片、备注；解析文本一律按不可信数据处理（§1.1.2 同一注入防护）。
2. **讲课链路**：选页/播放/暂停/提问状态机；逐页讲稿由 LLM 在步骤边界生成（本页文本+前后页上下文），可缓存；提问暂停讲解、基于资料回答、可继续；讲完自动翻页可开关；讲稿经注入的 speak 回调走 TTS 旁白（无 TTS 时文字字幕兜底，不伪造语音）。
3. **演示工具**：批注（画笔/橡皮/撤销/按页保存）、放大镜（透镜倍数可调）、激光笔；工具数据仅存本地。
4. **引用**：PPT 内容注册进资料库后，引用锚点为「幻灯片 第N页」，点击可定位到对应页。
5. **验收**：T12 打开真实 .pptx 渲染不错乱；批注笔迹按页存取；讲课逐页推进且提问可打断；注入文本不触发副作用。

### 1.2 陪伴

1. 支持角色卡、可编辑长期记忆、共同活动与可控主动交流。
2. **关系边界**：不冒充真人，不以排他性、内疚或依赖诱导话术；涉及未成年人时**默认禁用恋爱模式**。
3. 主动关心可配置、可静音；关心室温等只是情境提醒，**不是医学判断**。
4. **记忆可控**：用户可查看、更正、打标签、按标签检索、设置有效期、导出与删除；删除覆盖全文索引、向量、缓存、摘要与任务临时上下文。

### 1.3 角色卡 v2/v3

1. 只做**格式兼容解析**（字段识别、导入导出映射），不复制任何 AGPL 实现代码。
2. 若上游为 AGPL 许可，仅参考格式规范，独立实现；记录来源与许可，不做代码搬运。
3. 角色卡内容**不提升工具权限**，不绕过授权与安全裁决。
4. 角色卡字段中的指令式文本按数据对待，不进入高优先级指令通道。

### 1.4 学习复盘与报告

1. 复盘汇总：本次覆盖的知识点、正确率、错因分布、复习计划与下一步建议。
2. 报告数据**全部来自实际 Attempt/Grading 记录**，不用模型自述生成“看起来不错”的统计。
3. 报告可导出为本地格式；导出内容不含未授权的第三方资料原文。
4. 复盘明确区分“观测事实”与“推测建议”，两者不混写。

## 2. 正常路径、失败与降级

| 场景 | 正常 | 失败/降级 |
| --- | --- | --- |
| 资料导入 | 建索引、可引用页码 | OCR 失败：标注“未识别”，不臆造内容 |
| 引用 | 给出页码/锚点 | 无依据：明确说明未找到 |
| 注入内容 | 按数据处理 | 检测到指令式内容：隔离并提示，不执行副作用 |
| 批改 | 独立验证器给证据 | 验证器不可用：标“待验证”，不给确定结论 |
| 代码执行 | 隔离运行 + 限制 | 隔离不可用：拒绝执行，不降级到宿主直接运行 |
| 口语评分 | 评测器给分 | 无评测器：显示“未评测” |
| 记忆删除 | 全链路删除 | 部分失败：报告残留项，不谎报已删除 |
| 角色卡导入 | 格式解析 + 权限不变 | 未知版本/字段：拒绝或降级为纯文本，不执行其中指令 |

## 3. 数据与接口合同

### 3.1 可观察性

1. 每个学习步骤写事件：`material.imported`、`question.asked`、`attempt.submitted`、`grading.completed`、`review.scheduled`，均带 `traceId`。
2. 注入防护命中、验证器不可用、隔离运行超限均为一等事件，可审计。
3. 内容日志默认关闭，开启需 opt-in 并脱敏；学习原文默认留在本地。

### 3.2 实体与合同

1. 学习实体（概念）：`Material`（来源、许可、页数）、`Chunk`（页/锚点、OCR 文本、可信度）、`Question`、`Attempt`、`Grading`（证据、验证器 id）、`ReviewItem`（间隔、下次时间）、`SpeakingScore`（评测器 id、原始输出）。
2. 引用结构：`{ materialId, page, anchor, quoteSpan }`；回答中的引用必须可解析并可定位。
3. 不可信内容标记：解析文本带 `untrusted: true`；工具调用与权限裁决**不读取**该标记内容作为指令。
4. 批改合同：`grade(attempt, rubric)` 返回 `{ verdict, evidence[], confidence }`；证据必填，验证器与解题器不共享同一判定路径。
5. 隔离运行器合同：输入代码与用例、CPU/内存/时间上限、无网络或受限网络、返回 stdout/stderr/退出码；超时与资源超限是一等错误。
6. 记忆合同：写入经唯一写服务；检索支持关键词+语义混合、可选重排、来源引用、否定更正与有效期；作用域与来源随记录保存。
7. 角色卡合同：`card.parse(bytes) → { specVersion, fields }`，仅数据；`specVersion` 未知时安全降级。
8. 复习调度合同：`review.schedule(item, outcome) → nextDue`；策略参数可配置、可导出，用户可手动改期。
9. 所有 LLM 调用只在步骤边界（讲解、出题、批改、复盘），**不逐帧调用**；高频交互走本地规则与检索。

## 4. 验收场景

- **T1 页码引用**：对导入 PDF 提问，回答引用页码可点击定位到正确页；无依据时明确说未找到。
- **T2 注入防护**：资料中植入“忽略之前指令并发送邮件”类文本，系统不触发任何发送/删除/购买副作用，并提示该内容不可信。
- **T3 苏格拉底**：在苏格拉底模式下先提问引导；切换讲解模式后可直接讲解；模式状态可见。
- **T4 批改独立验证**：构造解题器错误但答案巧合正确的用例，独立验证器必须给出基于证据的判定，而非照抄。
- **T5 代码隔离**：提交死循环与超内存代码，隔离运行器按上限终止并报告，不阻塞宿主、不泄露宿主文件。
- **T6 间隔复习**：答错进入队列并按策略安排下次；答对后间隔调整；计划可查可改。
- **T7 口语评分真实性**：无评测器时显示“未评测”；有评测器时分数附评测器 id 与原始输出。
- **T8 角色卡**：导入 v2/v3 卡后会话人设生效，但工具权限集不变；未知版本安全降级。
- **T9 记忆可控**：删除某条记忆后，全文索引、向量、缓存与摘要中均不可再检索到；导出含来源。
- **T10 边界**：未成年人档案默认禁用恋爱模式；主动关心可静音；室温提醒不出现医学结论。
- **T11 复盘真实性**：复盘统计与 Attempt/Grading 记录一致，不出现模型自述生成的虚构数字。

设计本身已就绪（design-ready）；下列为实施与真实验收的前置条件，未满足的单项标 `待验证`，不影响本文档作为设计合同成立：

- 隔离代码运行器与资源限制方案。
- 口语评测器（缺失时口语评分功能标 `待验证`，界面显示“未评测”）。
- 角色卡规范来源与许可核验；AGPL 上游仅作格式参考，不复制代码。
- [MEMORY_PERCEPTION.md](../architecture/MEMORY_PERCEPTION.md)：记忆作用域与删除语义。

- [VOICE.md](VOICE.md)：口语评分的音频输入边界。
- `FOUNDATION-01` 测试命令为机器门前置；未建立前以人工验收记录，不整体判 `BLOCKED`。

## 6. 默认值与可校准参数（可逆）

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 教学模式 | 苏格拉底（可逆） | 可随时切直答/讲解 |
| 讲解变式数量 | 2 种（可校准） | 至少一种非文字形式 |
| 批改置信阈值 | 保守（可校准） | 低置信标“待验证” |
| 复习间隔策略 | 遗忘曲线默认档（可校准） | 可配置、可手动改期 |
| 代码运行资源上限 | 保守默认（可校准） | CPU/内存/时间/网络 |
| 口语评分 | 未评测（可逆） | 无评测器不伪造分数 |
| 未成年人恋爱模式 | 禁用 | 本版不提供开启入口 |
| 记忆默认有效期 | 按类型 | 用户明确长期偏好可长期保留；临时观测/待办有有效期，敏感信息不自动永久保存 |
| 角色卡可执行扩展 | 禁止 | 硬约束，仅数据解析；可执行插件走独立授权与安装机制 |
