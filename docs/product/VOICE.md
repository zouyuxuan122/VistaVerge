# 语音体验设计合同

状态：**待审批 / 未实施**。本文是设计合同（design-ready），不是代码。
上层依据：[最高设计](../../VISTAVERGE_DESIGN.md)、[工程规范](../../ENGINEERING_SPEC.md)、[协作规则](../../AGENTS.md)。
所有 CER、延迟、内存等数字均为**目标值或可校准参数**，未经真实硬件/真实供应商实测前不构成保证。产品运行时语音编排不逐帧调用大模型；LLM 只在回合与短句边界上工作，运行时 LLM 子智能体与开发期子智能体是两套不同机制。

## 0. 现状（已核实，可复现）

- 现有 `desktop/src/engine.ts` 的一轮对话为：噪声门/最短语音/停顿断句 → 云 STT → 云 LLM → 云 TTS(PCM) → 播放，**串行整段**；LLM 请求体显式为 `stream: false`。
- 现状是“整段等完再播”，不是流式，也没有渐进 ASR、真实流式 TTS、音素级口型时钟。任何界面文案不得把现状描述为流式。

## 1. 用户流程

### 1.1 目标链路

渐进 ASR（VAD 分段 + 增量转写）→ 回合/说话对象判断 → 流式 LLM → 稳定短句切分 → TTS（分句或真流式）→ 有界音频播放 → 播放时钟驱动口型。

### 1.2 可打断

用户可在**生成中、工具等待中、合成中、播放中**四个状态打断。打断后立即停止当前播放与合成，旧代际输出不得进入新回合。

### 1.3 常听与隐私

1. 持续常听默认**关闭**；开启需明确授权，并在界面持续显示拾音状态。
2. 常听在本地做 VAD/唤醒判断；未经同意不上传持续音频。
3. 提供静音时段、设备选择、一键停止与“本地处理”说明；回声参考与自播音频必须参与回声消除，避免把自己的声音当成用户输入。

### 1.4 主动插话

由确定事件、交流间隙与用户偏好仲裁，默认保守；不因“更活泼”而频繁抢话。

### 1.5 设备、路由与状态可见

1. 支持选择输入/输出设备；切换设备时重建音频图，并把“切换”视为取消当前代际，避免旧音频混入新设备。
2. 界面显示当前状态机状态：待机 / 拾音 / 识别 / 生成 / 合成 / 播放；用户可据此判断何时可打断。
3. 输出设备变化（拔插耳机）时暂停并显式提示，不静默改路由导致漏听或重复播放。
4. 应用内音量/增益独立于系统音量，避免与宿主或其他应用冲突。
5. 状态变化写事件（含 `generation`），便于复盘与验收。

### 1.6 说话对象与语言

1. 回合判断包含“是否在对我说”：旁路对话、电视声、他人交谈不应默认当作指令；不确定时降低主动响应。
2. 中英混说按供应商能力处理；能力缺失时显式显示限制，不静默丢弃。
3. 说话人切换（多人场景）不得串改上一位的记忆作用域。

## 2. 正常路径、失败与降级

| 场景 | 正常 | 失败/降级 |
| --- | --- | --- |
| ASR 流式 | 增量转写、低延迟 | 供应商不支持流式：显示“分句/批式”，不伪装流式 |
| TTS 流式 | 真流式首音快 | 仅支持整段：走分句合成，逐句排队播放 |
| 能力协商 | 按供应商能力描述选择路径 | 能力未知：按最保守批式处理并记录 |
| 播放 | 播放时钟驱动口型 | 时钟不可用：降级包络口型并标注非真实 viseme |
| 打断 | 全状态取消 | 取消失败：强制静音并记录，不继续播旧音频 |
| 音频缓冲 | 背压正常消化 | 见 3.4：暂停上游或显式失败，**不丢帧** |
| 模型常驻 | 按需加载 | 空闲超时热卸载释放内存；卸载失败上报不静默 |

降级必须可观察：记录能力、路径、原因与代际。

## 3. 数据与接口合同

1. **代际取消**：`generation` 贯穿 ASR/LLM/TTS/播放；取消使该代际所有状态失效（缓冲、队列、播放、口型）。新回合不复用旧代际任何音频或文本。
2. **回合语义**：用户新发言**开启新回合**（`generation++`），不是自动续播旧话。旧回合被取消或未播完的内容不因新发言而自动接着播。
3. **播放账本（actual played text）**：逐句/逐段记录“已确认播放完成”的文本单元。无音素对齐时，账本粒度**只能是句级/段级**：
   - 重试从**最后一个已确认完成的句子/段边界**之后开始；
   - **不承诺“第 2 句中间”这类精确文本断点**，因为无音素对齐时无法确定句中位置；
   - 句内被打断时，该句整体视为未完成（可能整句重播），不谎称精确续播。
4. **有界音频通道与背压**：实时音频走有界二进制通道，UI 状态不承载逐帧 PCM。缓冲将满时按序执行：**暂停上游生产（背压）→ 必要时等待 → 仍无法消化则显式失败**并上报。**不得任意丢语音帧**造成缺字、吞词；任何丢帧策略（若某路径必须丢弃）只允许在可证明不损语义的边界，且默认不启用。
5. **能力协商描述**（概念）：`asr.streaming`、`asr.partialResults`、`tts.streaming`、`tts.phonemeTiming`、`tts.sampleRate`、`llm.streaming`。UI 按此显示真实能力。
6. **ASR 质量指标**：中文 CER、短词/数字/专名错误率、噪声与远场、断句与说话对象判断、时延（首字/末字）、误触发率。评测集、样本来源、硬件、网络、冷暖态一并记录。
7. **TTS 质量指标**：发音（多音字、数字、专名）、韵律与停顿、长句稳定性、首音延迟、异常中断率。发音与韵律需专门用例，不止“接口返回 200”。
8. **模型管理**：模型按需加载，空闲热卸载；记录权重 hash、体积、许可、加载耗时与内存占用。
9. **设置分层**：`普通`（音色、语速、麦克风、常听开关、打断行为）+ `高级`（供应商能力、流式开关、VAD 阈值、超时、模型选择与卸载）。高级项默认折叠，改动有说明与回退。

## 5. 验收场景

- **V1 打断**：在生成/工具等待/合成/播放四个状态分别打断，均在目标时间内静音；新回合无旧代际文本或音频。
- **V2 账本重试**：播放完成第 1 句、第 2 句中途被打断后重试，从第 2 句**句首**开始（句级粒度），第 1 句不复播；不出现“从第 2 句中段精确续播”的声明。
- **V3 新回合语义**：播放中用户新发言开启新回合，旧内容不被自动续播。
- **V4 背压不丢字**：注入超过缓冲上限的音频流，系统暂停上游或显式失败；验证输出文本无缺字吞词，丢帧计数为 0（默认路径）。
- **V5 流式真实性**：供应商不支持流式时界面显示分句/批式；不存在把批式伪装成流式的路径。
- **V6 回声**：外放自播音频时，不把自身输出识别为用户语音；误触发在目标阈值内。
- **V7 中文 CER**：在固定评测集上给出 CER 与 P50/P95 时延，附样本、硬件、模型 hash、网络与冷暖态。
- **V8 发音韵律**：多音字、数字、专名、长句用例通过；失败项列出，不用“整体可接受”代替。
- **V9 热卸载**：空闲超时后模型卸载，内存回落可测；再次使用时按需加载成功。
- **V10 隐私**：常听关闭时不拾音上传；开启时状态可见；静音时段生效。
- **V11 说话对象**：播放第三方语音/电视声不触发指令执行；多人对话不串记忆作用域。
