# UI / UX / 角色设计合同

状态：**待审批 / 未实施**。本文是设计合同（design-ready），不是代码，也不是已完成声明。
上层依据：[最高设计](../../VISTAVERGE_DESIGN.md)、[工程规范](../../ENGINEERING_SPEC.md)、[协作规则](../../AGENTS.md)。
所有延迟、帧率、面数、体积等数字均为**目标值或可校准参数**，未经真实硬件实测前不构成保证。产品运行时的人形行为不逐帧调用大模型；LLM 只在回合事件上工作，运行时 LLM 子智能体与开发期子智能体是两套不同机制。

## 1. 用户流程

### 1.1 主布局

1. 窗口打开后，左侧约 **60%（目标，可校准）** 为电脑屏幕工作区，右侧约 **40%（目标，可校准）** 为角色坐在精致电脑前的三维场景。
2. 工作区顶部为四个互斥页签：`对话`、`本机只读镜像`、`AI 工作区`、`当前任务`。切换页签不结束会话、不重置权限。
3. 底部为悬浮**椭圆胶囊导航**，五个入口：对话、学习、任务、插件、设置。胶囊不遮挡输入框，也不遮挡角色手部与键盘接触区；角色手部与胶囊重叠时按布局规则让位（胶囊贴底、输入框上移）。
4. 最小窗口 1280×720（目标）下，左右两栏与胶囊仍不重叠；窄窗时右侧场景可折叠为窄条，会话与任务不丢。

### 1.2 主题与渲染格式解耦

1. 左上角切换 `手绘` / `写实`。这是**主题（视觉语言）维度**，与角色渲染格式**解耦**：
   - 手绘主题可驱动**二次元 VRM**，也可驱动 Live2D；写实主题同样可驱动 VRM。
   - 主题负责配色、线条、场景风格、UI 组件外观；渲染格式负责骨骼/参数/材质。
   - 因此**不把“手绘”硬绑到 Live2D**，也不因缺少 Live2D SDK 就禁用整个手绘主题。
2. 主题切换**不丢会话、不丢记忆、不改权限**；选择按用户档案持久化。
3. 主题与渲染格式是两个独立配置项，任意组合（在资产支持范围内）都应可渲染；组合不受支持时保持当前组合并提示原因。

### 1.3 角色渲染分层

1. 默认形象必须是**有合法来源的真实 VRM**；三段视频不是骨骼模型，不能作为默认形象。
2. 动作按层合成，层间可独立开关与调参：眨眼、视线（gaze）、表情、讲话（viseme/口型）、倾听、打字、鼠标动作、手部 IK。
3. 手部 IK 与桌面接触是美术验收项：手必须落在键帽/桌面合理位置，不允许穿模、漂浮或随镜头抖动。
4. Live2D 是独立可选适配器：只有真实参数与动作组驱动才算实现；不得用整幅画面缩放冒充口型同步。

### 1.4 聊天编辑、复制与分支

1. **编辑历史用户消息**：从该点**创建新分支**，原分支保留可回溯；不就地覆盖历史。
2. **复制消息**：把该消息的**纯文本复制到剪贴板**，不创建分支、不改动会话结构。
3. **复制分支**：作为**独立可选功能**（首期非必需，标记 `可选/后续`）——复制当前分支为独立分支，分配新 `branchId` 与新的 `turnId` 序列。
4. 撤回或切换分支**不等于撤销已执行的外部动作**（发送、购买、提交、家居控制等）；UI 必须显式提示这一点。

### 1.5 本机只读镜像 与 AI 隔离工作区

1. `本机只读镜像`：展示宿主屏幕的只读画面，**不可输入、不可作为执行平面**。命名、配色、图标与 AI 工作区明确区分，避免误认为可操作。
2. `AI 工作区`：应用拥有的独立浏览器或隔离环境，是默认执行平面。
3. **AI 大光标只绘制在 AI 工作区视口内部**，不创建桌面顶层光标窗口；宿主 `SetCursorPos` / `SendInput` / `SetForegroundWindow` 不得成为隐藏降级路径。
4. 映射视口不创造第二套输入环境。任意原生应用无法满足隔离时报告“不支持”，不偷偷接管宿主。

### 1.6 可访问性与输入

1. 键盘可达：页签、胶囊导航、消息编辑/复制/分支、急停均可键盘操作；焦点顺序稳定，不因三维场景抢焦点。
2. 输入法：中文 IME 组合期间不提交、不触发发送；`Enter` 与 `Shift+Enter` 行为明确。
3. 动效：提供“减少动态效果”开关；主题切换、场景动画与口型微动遵守该设置。
4. 对比度与字号：左侧功能文字为 DOM 渲染，提供字号档位与高对比模式，不因三维透视牺牲可读性。
5. 只读镜像与 AI 工作区使用**非颜色依赖**的区分标记（图标 + 文案），照顾色觉差异。
6. 错误与降级提示使用文本而非仅图标，且可被读屏软件读取。

## 2. 正常路径、失败与降级

| 场景 | 正常 | 失败/降级 |
| --- | --- | --- |
| 加载 VRM | three-vrm 加载并绑定分层 | 资产缺失/损坏：显示占位并标注未就绪，不退回视频假装模型 |
| 加载 Live2D | Cubism 适配器加载真实参数 | SDK 未就绪：仅禁用 Live2D 渲染格式，手绘主题仍可用 VRM |
| 主题切换 | 会话与权限保持 | 目标组合资产缺失：保持当前组合并提示 |
| 口型同步 | 音频播放时钟驱动 viseme | 无音素时长：降级为包络驱动并**明确标注非真实 viseme** |
| 手部 IK | 接触点稳定 | IK 解算失败：回到基础姿态，不摆出穿模姿势 |
| 导入玩家模型 | 校验并登记许可元数据 | 未声明许可/来源：拒绝导入并给出说明 |
| 只读镜像 | 只读展示 | 宿主采集被拒：显示授权引导，不静默开启 |

降级一律可观察：写事件与原因，不吞错，不用“看起来正常”掩盖。

## 3. 数据与接口合同

1. 事件统一带 `sessionId / turnId / generation / traceId`；渲染与 UI 状态不承载逐帧 PCM。
2. **映射与坐标合同**：以 `surfaceId` 标识目标执行面；坐标使用**视口 CSS 坐标**与 **guest pixels**，每帧带 `frameId`。执行坐标一律使用映射视口内的 guest 坐标，**不使用宿主屏幕坐标作为执行坐标**。只读镜像面禁止接受任何输入坐标。
3. 角色运行时接口（概念）：
   - `avatar.load(profile)`：返回能力集（是否支持 viseme、IK、表情预设）。
   - `avatar.applyLayer(layer, params, generation)`：带代际，旧代际调用丢弃。
   - `avatar.setAudioClock(source)`：以 Web Audio 播放时钟为主时钟。
4. 音频时钟对齐：口型采样读取播放时钟 `currentTime`，暂停/结束/取消时立即闭口，不残留张合。
5. 模型导入合同：`model.import(glb, licenseDeclaration)`；许可字段必填，存储来源、许可名、用户声明时间；默认本地使用，不自动上传、不进入默认分发。
6. **GLB 质控按资源类型分别检查**（不套用统一的“必须单一骨架/无非流形”等普遍约束）：
   - **角色类（VRM/人形）**：单位与尺度、朝向、原点、骨架与骨骼命名、BlendShape/viseme 名称映射、材质与纹理存在性、表情预设覆盖。
   - **场景/道具/电脑类**：网格可分离性、命名规范、材质与纹理、可复用性、LOD 与三角面目标、碰撞代理是否必需。
   - **通用**：无未应用负缩放、无缺失外部引用、纹理尺寸在目标预算内。
   - 每类检查项与阈值是**可校准参数**，按资产类型配置；源场景与导出 GLB 都留档。

## 4. 验收场景

- **A1 布局**：1920×1080 下左约 60%/右约 40%（目标），胶囊不遮输入框与手部；缩放至 1280×720 仍不重叠。
- **A2 主题与格式解耦**：手绘主题 + 二次元 VRM 可正常渲染；写实主题 + VRM 可渲染；主题切换往返后会话、记忆、权限、任务不变。
- **A3 口型**：播放中暂停 100ms 内闭口；取消后不出现残留口型或旧音频。
- **A4 时钟对齐**：以音频时钟为基准，口型与音频偏移在目标范围内；测试需给出样本、硬件、模型 hash 与 P50/P95。
- **A5 手部 IK**：逐帧采样手-桌面接触，穿模帧数为 0；由美术验收签字，不用编译通过代替。
- **A6 许可门**：导入未声明许可的玩家模型被拒绝；已声明模型可导入且元数据可查。
- **A7 隔离与坐标**：移动 AI 大光标期间，采样宿主鼠标坐标不变；只读镜像点击不产生宿主输入；输入坐标全部来自 `surfaceId + guest pixels + frameId`，无宿主坐标路径。
- **A8 复制语义**：复制消息只写剪贴板、不产生分支；编辑消息产生新分支且原分支可回溯；“复制分支”若实现则 id 唯一，未实现时入口不出现或明确标注。
- **A9 真实性**：不存在“音量缩放整幅画面”式伪口型；无真实 VRM 时界面明确标注未就绪。

## 6. 默认值与可校准参数（可逆）

以下给出**可逆默认值**，均可通过设置或配置调整；标注 `可校准` 的需在真实硬件上实测后定稿：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 左右分栏比例 | 60/40（可校准） | 实测后定稿，允许用户手动调整 |
| 默认主题 | 写实工作室（可逆） | 手绘为完整可选主题，切换不丢状态 |
| 默认渲染格式 | VRM（可逆） | 资产就绪前显示未就绪占位 |
| 口型驱动 | 音频时钟 + viseme（可校准） | 无音素时降级包络并标注 |
| 窄窗场景折叠阈值 | 1280px（可校准） | 低于阈值折叠为窄条 |
| GLB 三角面/纹理预算 | 按资源类型配置（可校准） | 角色与道具分别设定 |
| 大光标样式与急停位置 | 光标跟随目标；急停固定视口右下 | 高对比大光标不得固定在角落冒充目标轨迹 |
| 手部 IK 开关 | 开（可逆） | 解算失败回基础姿态 |
