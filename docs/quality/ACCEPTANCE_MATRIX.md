# 真实功能验收与体验调优矩阵

2026-09-18 / 待审批。数值全部为**待达到的工程目标**，不是已实测结果。上层：[最高设计](../../VISTAVERGE_DESIGN.md) §2.5；[工程规范](../../ENGINEERING_SPEC.md)。

## 1. 三层证据与状态

1. 机器门：类型/合同/单测/集成/GUI断言，命令rc=0且断言有意义。
2. 独立证据：前台复跑关键项，核对服务、模型、真实应用/设备与结果，不采用子智能体自述作PASS。
3. 一致性：需求/设计/允许文件域/真实行为一致；测试未覆盖的声明不得推断通过。

`NOT_STARTED/IN_PROGRESS/PASS/FAIL/BLOCKED`按任务使用；设计文档状态为待审批而非软件PASS。Mock只标CONTRACT或SIMULATED，真实基准标REAL；没有密钥、设备、资产、许可时列出缺失项与复現步骤。模拟通过不取消真实BLOCKED。

## 2. 统一基准记录

每次记录应用commit（无提交写uncommitted）、依赖锁hash、OS/WebView2、CPU/GPU/RAM、模型/权重hash、采样率/音频设备、provider区域、网络延迟、MC版本/服务端、数据集版本、开始结束、冷暖态、样本数、失败数、P50/P95/P99。耗时使用单调时钟，跨进程说明对齐方法。

初始性能设备是待测矩阵：低配CPU/核显+云、主流笔记本混合、高性能本地GPU，记录实机而非预先写死“最低显卡一定可用”。多帧多次采样，失败不能从分母剔除。

ASR质量：自建获授权普通话集≥100条，含数字、专名、短词、停顿、噪声与自播；预处理规则锁定后计算CER。初始目标清晰近场CER≤10%、噪声集≤20%，按真实数据审查是否适合产品，不为过门随意放宽。TV/背景误回应、漏回应、误写记忆分别统计。

TTS质量：≥60条中文/混合文本覆盖多音字、数字、单位、专名、标点、情绪、长句；记录首音、RTF、音频缺失、削波、发音错误与至少两位独立听评者的盲听评分。目标严重缺字/重复为0，固定关键词准确率≥95%，自然度中位数≥4/5；无听评者不能由模型自评代替真实听评。

这些质量目标在第一次真实基准后若确需调整须ADR说明质量/硬件取舍，安全硬约束不放宽。

## 4. 关键验收场景

### 4.1 语音与口型

生成/工具等待/合成/播音逐状态打断；取消后旧token/音频/viseme无残留。外放与耳机、不同麦克风、采样率、超长句、断网、TTS半包、奇数字节、回声、短词、持续噪声和设备拔出全覆盖。AEC不可用/不稳时明确半双工或按键说话降级，不假装全双工稳定。

无音素对齐只记录句/片段播放进度，不能承诺精确文本中断点。用户插话后开始新回合，不自动继续旧话。音频队列过载施加背压或明确失败，不能丢帧吞字。

### 4.2 UI、人物与聊天

实机Tauri与浏览器预览分别验证。真实VRM加载、动作/表情/手部/电脑材质现场查看；Live2D只有在资源与许可到位后单列通过。剪贴板复制、编辑分支、重试、取消、历史持久化、主题往返、键盘导航、减少动效均实际操作。截图是证据之一，不替代点击与业务断言。

### 4.3 无干扰电脑操作

静态检查宿主禁用API及包装入口，运行时独立采样鼠标/焦点/输入注入；静止和用户并发打字两组对照。证明AI目标真正改变且宿主未受干扰。DPI/多屏/窗口变化/frame过期/下载/弹窗/断线/急停；任何不支持场景明确停止，不偷用宿主。

### 4.4 记忆与主动提醒

中文短词和同义查询；标签any/all；越权/跨角色/跨项目零泄漏；否定更正/过期/冲突；删除后全文/向量/缓存/摘要/任务/重建/备份恢复不复活。索引模型更换与中途崩溃可恢复。

用户说出门+新鲜天气雨+今日材料→一条有来源提醒；用户说已带伞/取消出门→更新或取消；天气过期/无定位不编造。16℃一小时用虚拟时钟单测持续条件，再在HA测试实例实跑定时/断线/重连，不用快进单测冒充一小时实际事件稳定性。

### 4.5 教师与陪伴

至少一份真实资料完成导入→来源问答→诊断→练习→独立批改→错因→下一次复习。故意错误解答、伪造引用、OCR注入、无评测器口语评分、代码死循环/文件访问等反例。学习数据与伴侣记忆可区分；角色卡不能改工具权限。

### 4.6 MC及连接器

固定Java游戏版本/server/Mineflayer/种子，跟随、停止、采集、合成、搭建、死亡恢复、背包满、障碍、受击开关各实测。任务进行中用户语音提问与打断，不把游戏公屏聊天当成右侧角色语音验收。

GitHub读权限巡检不产生写请求；QQ/微博真实发送使用授权测试账号/收件人，不向真实联系人试发；HA读写与天气城市/时效明确。缺真实环境保持BLOCKED。

### 4.7 插件与发布

合法源/损坏包/错误签名/新增权限/依赖冲突/恶意解压/崩溃恢复。干净Windows VM安装、升级、卸载、签名拒绝、旧配置与数据库备份恢复；体积/模型下载/断点续传/退出残留进程实测。

## 5. 调优闭环与终止条件

每项：固定数据集建基线 → 只改变一个主要变量 → 重跑同集与留出集 → 比较质量/延迟/资源/Token → 记录取舍 → 保留回归。拒绝只调演示句子；阈值默认来自实测，高级设置允许用户按噪声/硬件调整。

完成条件是预定场景成功、质量/延迟目标满足或明确批准的产品取舍、关键错误归零、前台独立复跑一致。环境无法满足时给出失败分解和阻塞，不用“后面优化”宣布完成。
