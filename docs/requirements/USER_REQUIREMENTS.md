## 2. 边界不是删除需求

- “所有电脑”采取能力分档，不承诺无GPU也能跑所有大模型；文字/云端/关键词检索提供明确降级。
- “像真人”拆为交流连续性、感知证据、语音/动作协调与任务成功率，不作无法证明的真人级承诺。
- “MC源码定制”用合法协议/模组或官方服务端方式满足操控目标，不再分发来源不明游戏整包。
- “复制”默认消息进剪贴板，不擅自改成复制分支。
- “本机不动”是输入/焦点隔离，不保证网络账号的副作用不会出现在同账号其他设备；发送依旧需授权。
- “所有功能都加上”用有边界阶段覆盖，不增加没有需求/验收的空功能按钮。
