# 插件、仓库源市场、安装与维护更新

状态：待审批 / 未实施。依据：[最高设计](../../VISTAVERGE_DESIGN.md) §2.3、§4、§9。

## 1. 平台对象

模型、ASR/TTS、记忆索引、角色、场景、主题、工具、教师技能、游戏、家居、Agent 策略、UI 面板均可替换。权限/凭据/审计/签名验证属于可信核心，不通过插件免检。

PluginManifest：唯一ID、版本、入口种类、SDK/API兼容范围、OS/架构、依赖、许可证、发行者、资源体积、设置schema、权限请求、内容摘要、签名引用、迁移版本。资源包为数据，不能携带隐蔽安装脚本。

权限包括：provider端点、域名、文件目录、surface、家居实体、记忆scope、账号写操作；不只有一个“允许访问电脑”的全权开关。更新新增权限保持禁用，用户同意后才能激活。

## 2. 信任与宿主

声明式扩展优先。第三方 UI 不共享主 WebView 的原生桥。纯 JS Worker/Node 子进程不是安全沙箱；可执行原生插件在有效 OS 隔离未验证前必须标记“受信任原生代码”，默认不自动运行，不宣传成权限可完全约束。

MCP 对接仍走同一权限、预算和审计。远程工具返回不是授权。第三方 Agent 策略不能绕过宿主进行网络/文件/密钥访问。隔离难以做到的平台明确减少功能。

## 3. 仓库源与安装事务

添加 GitHub 仓库或 HTTPS index；显示来源、发行者、信任指纹、刷新时间与代理设置。初期使用明确 JSON schema 的静态索引+release资源，不执行仓库里的脚本生成索引。

索引版本、最低客户端版本、插件各版本、平台包、sha256、签名、许可证/来源链接。哈希只验证一致，发行者签名建立信任；首次信任公钥、轮换、撤销与源被接管的响应要有 UI。只有官方/用户已信任源可自动刷新，自动安装仍按设置。

安装：resolve → 下载到临时目录 → 哈希/签名/路径与体积校验 → 依赖兼容检查 → 暂存 → 安装事务 → 健康检查 → 原子启用。失败保持旧版本，不留下半启用状态。

防护：zip-slip、symlink逃逸、解压炸弹、依赖循环、缓存投毒、降级攻击、重定向到未批准域、manifest字段超限、并发卸载。卸载可保留数据或显式删除，权限随停用撤销。

## 4. 社区开发与版本合同

提供 SDK、数据包/只读工具/领域动作三类示例、manifest校验器、假权限宿主、取消与错误fixture、发布清单。API SemVer，写明支持窗口与弃用日期；插件引用 SDK 而非主项目内部路径。

发布前证据含来源、许可证、资产授权、兼容矩阵和测试。VRM读取对应版本meta并按商业/修改/再分发/允许使用者约束处理；元数据不足则按最小允许范围，不把本地导入同意当再分发授权。Live2D SDK/模型分别核查。品牌角色默认可选社区包，不暗示品牌背书。

## 5. 定制安装与首次运行

Windows NSIS 定制品牌、信息层级与进度页；保留系统 UAC/SmartScreen等提示，不绕过安全。可选路径、组件、快捷方式和隐私说明，展示总下载量与可用空间。安装前检查支持的Windows/WebView2/CPU架构，失败有恢复入口。

首次启动：硬件探测 → 轻量云端/混合/本地 → 麦克风与播放测试 → 合法角色预览 → provider测试 → 权限概览 → 一次真实试聊。默认不同时下载所有大模型。断点续传、校验、离线包与清理有独立状态。

## 6. 更新与维护

Tauri updater签名验证独立于HTTPS。私钥不入库或插件，发布流程验证公钥轮换、撤销、版本回退策略与签名失败。稳定/预览渠道隔离；默认更新检查按用户设置，不强制活跃会话重启。

应用、插件、模型、角色分别版本化。更新 UI 显示内容、权限差异、下载/校验/迁移阶段、安装时间与“稍后”。数据库迁移先一致性备份，事务失败恢复；二进制旧版本不能读取新schema时不可简单降级。

发布支持矩阵记录应用/SDK/provider/MC/server/角色格式/Windows与驱动。故障报告脱敏导出，不自动附完整对话、音频、密钥或私人源码。版本依赖安全更新经过回归后发布，不在用户运行时随意漂移latest。

## 7. 验收

- 添加私有/公开测试源、离线、限流、过期索引；界面不误报已刷新。
- 合法安装成功，篡改/签名不符/不兼容/路径穿越拒绝；升级新增权限阻止自动启用。
- 装到一半断电/异常退出、卸载再装、迁移失败、回滚、用户数据保留，状态一致。
- 干净Windows VM安装/升级/卸载；模型下载失败可续，失败不影响已可用文字模式。
- 真实签名开发包演练；无正式签名不声称可面向公众安全自动更新。

当前没有实现清单解析器、市场或更新机制；对应工作由 PLUGIN-01 与 RELEASE-01 在基础合同通过后制作并审批。
