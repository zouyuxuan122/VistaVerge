# 领域插件设计合同

状态：**待审批 / 未实施**。本文是设计合同（design-ready），不是代码。
上层依据：[最高设计](../../VISTAVERGE_DESIGN.md)、[工程规范](../../ENGINEERING_SPEC.md)、[协作规则](../../AGENTS.md)。
所有成功率、延迟、阈值等数字均为**目标值或可校准参数**，未经真实环境实测前不构成保证。领域插件的人形行为不逐帧调用大模型：本地反应与行为树处理高频，LLM 只做高层规划；运行时 LLM 子智能体与开发期子智能体是两套不同机制。

## 1. 用户流程

### 1.1 Minecraft

1. **固定 Java 版本 + 受控服务器**：明确记录 Java 版本、服务端类型与版本、Mineflayer 版本；不混用多套重叠框架。
2. **分层控制**：Mineflayer 本地反应（避障、跟随、拾取）+ 行为树/技能（挖矿、合成、建造）+ LLM 高层规划（目标拆解、顺序调整）。**不逐帧调用 LLM**。
3. **真实联机边玩边聊**：任务成功以真实服务器内实际完成为准；聊天走真实多人环境，不造假连接、不造假成功。
4. **PvP 控制**：攻击/反击反应受 PvP 开关约束；关闭时不得自动攻击玩家。不规避反作弊。
5. **Bot 可见**：不隐藏 bot 存在；对同服玩家可识别，行为受用户配置约束。
6. 不可逆动作（放置/破坏大范围、丢弃贵重物品）按授权与确认执行。

### 1.2 家居（Home Assistant 优先）

1. 通过 Home Assistant 接入传感器与设备；权限最小化，用户授权后方可读取。
2. **16℃ 一小时场景**：按**用户意图与可得证据**触发提醒，不强制要求同时具备“设定”和“实际”两个传感器。有实际温度就用实际；只有设定温度时说明“这是设定值”，不得说成实际温度；设备断线时说明未知。占用状态缺失不强行阻塞保守提醒；安静时间限制主动播报，但不阻止用户主动询问或明确请求的控制。
3. 关心室温是情境提醒，**不是医学判断**，不输出健康诊断；证据不足时说明依据与不确定，而不是拒绝提醒。
4. 家居控制属副作用动作，需对应授权；安静时段默认不主动打扰。

### 1.3 天气与出门

1. “我要出去了，再见”触发出门场景：查**新鲜**天气 + 检索今天出行相关记忆 + 合并为一条简短提醒。
2. 天气过期或无定位时说明不确定，**不胡编实时天气**。
3. 可依据近期对话说“今天要带的资料别忘了”；不得凭空断言“你没带钥匙”。
4. 出现反证（已带伞、不出门）时取消提醒。

### 1.4 GitHub PR/Issue 巡检

1. 默认**只读**：拉取 PR/Issue 列表、状态、评论；巡检结果可摘要提醒。
2. 定时工作必须由用户显式配置；token 作用域最小化，凭据不进日志/报告。
3. 任何写操作（评论、关闭、合并、推送）需单独明确授权，不因“巡检”授权扩展为写权限。

### 1.5 QQ / 微博

1. **首期**只生成**草稿与预览**，**默认不自动外发**。
2. **后续目标**：在存在合法官方 API，或在隔离环境且用户明确授权的前提下，实现**实际发送**；发送是独立授权域，不因“草稿”授权而自动获得。
3. 不假设可操作宿主现有登录；如需自动化，必须在隔离环境安装与单独登录，且不干扰宿主。
4. 无官方 API 或隔离不满足时报告“不支持”，不偷偷接管宿主输入。

### 1.6 通用插件边界

1. 每个领域插件声明权限、依赖、许可证、设置 schema 与发行者；权限增加需重新同意。
2. 插件是数据与受限能力，**不是高优先级指令**；插件内容不得提升自身权限或绕过可信核心。
3. 安装/更新走事务校验（路径穿越、解压体积、依赖循环）；插件与应用可独立更新。
4. 网络与凭据访问按最小作用域授予；凭据不进日志、快照与报告。

## 2. 正常路径、失败与降级

| 场景 | 正常 | 失败/降级 |
| --- | --- | --- |
| MC 连接 | 固定版本连接受控服务器 | 版本不匹配/断线：报告并停止，不伪造在线 |
| MC 规划 | LLM 高层 + 本地行为树 | LLM 不可用：降级到本地技能，不卡死不动 |
| MC 攻击 | 受 PvP 开关约束 | 开关关闭：不攻击，仅规避 |
| HA 读取 | 读取设定/实际/占用/在线 | 实体不可用：标注未知，不猜数值 |
| HA 控制 | 当前授权范围内执行用户明确命令 | 未授权拒绝；安静时段抑制主动建议/播报，不擅自延迟用户已明确请求的合法控制 |
| 天气 | 新鲜数据 | 过期/无定位：说明不确定 |
| GitHub | 只读巡检 | 认证失败/限流：报告并退避，不重试轰炸 |
| 社媒草稿 | 生成草稿与预览 | 无法隔离操作：仅给草稿，不自动发送 |
| 社媒发送 | 合法 API 或隔离+授权后发送 | 未授权/无合法通道：保持草稿，不接管宿主 |

## 3. 数据与接口合同

1. 统一事件带 `taskId / actionId / traceId / observedAt / expiresAt / source`；外部观测有过期语义。
2. MC 合同（概念）：`mc.connect(server, version)`、`mc.skill(name, params)`、`mc.plan(goal)`、`mc.chat(msg)`；`mc.status()` 返回真实连接与玩家可见性。任务结果必须来自游戏内验证，不用“接口返回 200”代替。
3. PvP 配置：`pvp.enabled`、`pvp.retaliate`；默认保守，关闭时不主动攻击。
4. HA 合同：`ha.read(entityId)` 返回 `{ state, attributes, observedAt, available }`；`ha.control(entityId, action)` 需授权，返回真实执行结果。
5. 温度语义：`setpoint` 与 `measured` 分开字段；`available=false` 时禁止生成确定性温度陈述。
6. 天气合同：`weather.get(location)` 返回 `{ data, observedAt, expiresAt, confidence }`；过期即视为不可用。
7. GitHub 合同：`github.listPR/listIssue(repo, filters)` 只读；写接口单独授权域，默认未授予。
8. 社媒合同：`social.draft(platform, content)` 只产出草稿；`social.publish` 默认禁用，需单独授权并使用合法官方 API 或隔离环境自动化。
9. 所有副作用动作走统一授权与审计；插件不得绕过可信核心。
10. 领域插件运行在受管理 sidecar/插件沙箱边界内，不与应用可信核心共享无约束权限。

## 4. 验收场景

- **D1 MC 真实成功**：在真实受控服务器完成一次多步任务（如采集并合成），以游戏内状态验证成功，附服务器与版本信息。
- **D2 MC 边聊**：MC任务进行中，用户通过麦克风与右侧角色真实语音交流，口型与播放同步，用户能打断且游戏任务状态可说明；游戏公屏消息是附加场景，不能替代上述语音验收。
- **D3 MC PvP**：`pvp.enabled=false` 时被攻击不还手；开启时按配置反应。
- **D4 MC 可见性**：同服玩家可识别 bot；无隐藏 bot 的机制。
- **D5 MC 无逐帧 LLM**：运行期采样显示 LLM 调用只发生在规划边界，高频控制由本地逻辑处理。
- **D6 16℃ 一小时**：仅有设定温度时文案明确标注“设定值”；有实际温度时区分两者；断线时显示未知；**不要求同时具备两个传感器**即可基于可得证据给出提醒，并说明依据与不确定。
- **D7 出门提醒**：出门场景给出新鲜天气 + 相关记忆的一条简短提醒；天气过期时说明不确定；已带伞时取消提醒。
- **D8 GitHub 只读**：一次巡检产生零写操作；token 作用域最小；限流时退避。
- **D9 社媒草稿**：QQ/微博只生成草稿，未授权时零外发；无法隔离时报告不支持。
- **D10 权限边界**：插件内容不能提升自身权限；不可逆动作需确认；插件不绕过可信核心。
- **D11 插件安装事务**：构造路径穿越、超大解压、依赖循环的插件包，安装被拒绝并报告；正常插件可安装、可停用恢复。
- **D12 凭据脱敏**：运行后检查日志与报告中不含 token、密钥或账号明文。

## 6. 默认值与可校准参数（可逆）

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| MC PvP | 主动攻击关（可逆） | 反击按配置 |
| MC bot 可见性 | 可见（不可逆的默认） | 不提供隐藏机制 |
| MC 任务超时 | 可配置（可校准） | 超时报告失败，不谎报成功 |
| 温度告警阈值 | 保守（可校准） | 区分 setpoint/measured |
| 温度提醒依据 | 意图 + 可得证据（可校准） | 不强制两个传感器；缺证据时说明不确定 |
| 安静时段 | 夜间默认（可逆） | 可调整 |
| 天气新鲜度窗口 | 短窗口（可校准） | 过期视为不可用 |
| GitHub 巡检频率 | 用户配置（可校准） | 默认不开启定时 |
| GitHub 写权限 | 未授予（可逆） | 需单独授权 |
| 社媒外发 | 首期禁用（可逆） | 后续合法 API 或隔离+授权后实际发送 |
